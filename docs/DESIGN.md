# 小纸条 · 视觉规范

更新日期：2026-10-20。本文是界面改动的唯一判据：新增页面、新增组件、调整样式都先对照这里。

配套记录：[UI 审计与验收](UI_AUDIT.md)、[UI 待修改事项](UI_TODO.md)。规则来源是 Refactoring UI 的十二条法则，落地时按本仓库的 token 体系翻译。

## 1. 设计方向

「暖石灰纸 + 深咖书脊 + 朱砂」：外壳是深色的笔记本封面，内容区是纸面。主色只用来标记「该做什么」，不用来装饰整块区域。

- 深色只出现在两处：左侧导航栏、手机底部导航栏、登录页左栏。内容区永远是纸面。
- 一个页面最多一个实心主按钮。只读页面（统计、约定、收件箱）没有主按钮。
- 装饰让位于层级：胶带、插画、点阵底纹只在首页 hero 与登录页出现。

## 2. 颜色

色阶由 `refactoring-ui` 的调色脚本从五个基色生成（ember `#B4452B`、sage `#5A7050`、ochre `#8C5A14`、danger `#9C2E26`、暖灰手调），全部落在 `apps/web/src/styles/tokens.css`。

| 语义   | Token       | 值        | 用途                   |
| ------ | ----------- | --------- | ---------------------- |
| 页面底 | `--canvas`  | `#F4F1EC` | 内容区背景             |
| 卡片面 | `--surface` | `#FFFDFB` | 面板、卡片、弹窗       |
| 主文字 | `--ink`     | `#1E1A17` | 标题、正文             |
| 次文字 | `--muted`   | `#554E48` | 说明、元信息           |
| 弱文字 | `--subtle`  | `#6A625B` | 时间、计数、图标       |
| 描边   | `--border`  | `#E3DCD3` | 1px 边                 |
| 主色   | `--primary` | `#B4452B` | 主按钮、强调、当前步骤 |
| 成功   | `--sage`    | `#5A7050` | 已和好、跟进中         |
| 提醒   | `--warning` | `#8C5A14` | 待回访、待确认         |
| 危险   | `--danger`  | `#9C2E26` | 删除、关闭空间         |
| 导航底 | `--rail`    | `#221E1B` | 侧栏、手机底栏         |

实测对比度（`check_contrast.py`）：正文 `--ink` 15.3:1、`--muted` 7.4:1、`--subtle` 5.3:1、白字在 `--primary` 上 5.5:1、`--warning` 在软底上 6.4:1、`--danger` 在软底上 6.5:1。全部满足 WCAG AA；placeholder 也使用 `--subtle`，不再出现 2.5:1 的浅灰。

规则：

- 正文与元信息只用 `ink / muted / subtle` 三档，不再新增第四档灰色。
- 灰字不放在彩色底上；彩色底上用同色系的深色文字（如 `--ochre-700` 在 `--warning-soft` 上）。
- 颜色不能是唯一信号：状态徽章同时带圆点、文字与底色。

## 3. 字体与字号

- UI 字体：`Inter, 'PingFang SC', 'Microsoft YaHei', system-ui`；展示字体：`'Noto Serif SC', 'Songti SC', 'Source Han Serif SC', 'SimSun', serif`。
- 只有六档字号，禁止出现第七档：

| Token        | 值   | 用途                         |
| ------------ | ---- | ---------------------------- |
| `--text-xs`  | 12px | 元信息、标签、按钮小号       |
| `--text-sm`  | 14px | 正文、导航、表单             |
| `--text-md`  | 18px | 区块标题、卡片标题、弹窗标题 |
| `--text-lg`  | 24px | 数字强调、封面标题           |
| `--text-xl`  | 30px | 页面标题（宋体）             |
| `--text-2xl` | 40px | 登录页主标题（宋体）         |

- 层级跳跃必须跨两档以上；12 与 14 只用于「元信息 vs 正文」，不承担层级。
- 中文正文行宽 28–36 字，即 `max-width: 32em`（`--measure`）；行高 1.75，标题 1.2–1.4。
- 字重只有 400 / 500 / 600；不使用 700 以上。

## 4. 间距、圆角、阴影、断点

- 间距八档：`4 8 12 16 24 32 48 64`（`--space-1..8`）。组内间距 ≤12，组间距 ≥32。
- 圆角四档：`8 / 12 / 16 / 20`（`--radius-sm..xl`），胶囊用 `--radius-pill`。不再出现 9/11/13/18px 这类一次性值。
- 阴影三档：`--shadow-1` 卡片、`--shadow-2` 浮层/悬停、`--shadow-3` 弹窗。卡片优先用 1px 边表达层级，阴影只是补充。
- 断点三个：`640px`（手机）、`900px`（平板/侧栏收起）、`1200px`（宽屏）。新增断点前先证明现有三档无法表达。
- 触控目标 ≥44px；`:focus-visible` 用 `--focus` 2px 环；`prefers-reduced-motion` 下关闭过渡。

## 5. 组件档位

按钮只有四档，模板里不允许出现第五种：

| 档位   | 类名            | 场景                           |
| ------ | --------------- | ------------------------------ |
| 主行动 | `btn primary`   | 每页一个：保存、提交、去下一步 |
| 次要   | `btn secondary` | 并列选项、返回、筛选           |
| 轻量   | `btn quiet`     | 退出登录、撤销、收起           |
| 危险   | `btn danger`    | 仅确认弹窗里的破坏性确认       |

- 状态徽章 `badge` 统一为「圆点 + 12px 文字 + 软底色」，不再用实心色块。
- 表单标签 12px、控件 40px 高、错误与提示 12px；一个字段组最多两列。
- 空态、加载、错误三套状态各只有一个实现：`EmptyState`、`LoadingState`、`ErrorState`。

| 页面         | 主行动               | 备注                                                 |
| ------------ | -------------------- | ---------------------------------------------------- |
| 我们的小天地 | 写一张纸条           | hero 只做引言，不再承载第二个主按钮                  |
| 我们的纸条   | 写一张纸条           | 「查找」是次要按钮                                   |
| 写一张纸条   | 保存纸条             | 移动端按钮吸底                                       |
| 一起回头看看 | 下一步（动态）       | 分享 / 补视角 / 确认约定 / 填回访 / 结束跟进，五选一 |
| 共同约定     | —                    | 只读页，卡片内只有文字链接                           |
| 一起回顾     | —                    | 只读页，顶部是结论句而不是按钮                       |

## 7. 不要做

- 不要新增 hex 字面量到 `app.css` 或组件里；颜色只能来自 `tokens.css`。
- 不要用 10–11px 字号「显得精致」；12px 是下限。
- 不要用灰色降低彩色背景上的对比度（用同色系深色）。
- 不要在只读页加「主按钮」凑数。
- 不要给卡片同时上边框、阴影、胶带和底纹；选一种表达层级。
- 不要在新页面里引入 Tailwind 工具类：项目虽然装了 Tailwind v4，但界面全部由 `apps/web/src/styles/` 手写，两侧混用会让层级失控。

## 8. 已知边界

- 暗色模式未实现，但颜色全部走 token，后续加一组 `[data-theme='dark']` 覆盖即可。
- 标题仍使用系统宋体，没有自托管 webfont（见 UI_TODO 2.2），Windows 落 SimSun 属于已知差异。
- `app.css` 仍保留旧结构规则（布局与少量遗留选择器），新的视觉规则集中在 `overrides.css`；两者顺序不能调换。
